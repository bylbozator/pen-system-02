# Система управления заявками «ПЭН» (исправленная версия)

Корпоративная система для планирования и согласования потребностей в материалах, оборудовании и услугах.

## Быстрый старт

1. Запустите `make up` (или `docker-compose up -d`)
2. Откройте http://localhost (или https://localhost для HTTPS)
3. Логин: `admin`, пароль: `admin` (если не изменён в `.env`)

## Документация API

http://localhost:8000/docs

## Администрирование

- Пользователи и роли: в интерфейсе после входа (раздел "Пользователи" и "Роли")
- Массовое создание пользователей: CSV (логин,email,пароль,role_id,фамилия,имя,отчество,отдел)
- Импорт Excel для создания новой таблицы: кнопка "Загрузить Excel" на странице списка таблиц
- Мягкое удаление таблиц: таблицы уходят в архив, их можно восстановить
- Полное удаление таблиц из архива: только для администратора
